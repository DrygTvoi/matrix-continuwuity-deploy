# config/

Generated by `../setup.sh`; the files contain your domain and secrets and are
gitignored.

| File | Used by | Contains |
|---|---|---|
| `continuwuity.toml` | Continuwuity | server name, TURN secret, registration token |
| `livekit.yaml` | LiveKit | API key/secret, TURN credentials |
| `turnserver.conf` | coturn | TURN shared secret, relay port range |
| `element-web.json` | Element Web | homeserver URL, Element Call URL |
| `element-call.json` | Element Call | homeserver URL, LiveKit service URL |
| `ntfy.yml` | ntfy | push gateway base URL, access policy |
| `Caddyfile` | Caddy | all TLS sites and reverse-proxy routes |
| `proxy/` | existing reverse proxy | integration snippets (nginx, Caddy, Traefik, Apache, HAProxy) when externally terminated TLS is detected |

`fail2ban/` is *not* generated — it is a static filter installed by
`scripts/harden.sh`.

Re-running `setup.sh` overwrites these files but reuses existing secrets from
`.env`; pass `--rotate-secrets` to change them. `--reset-bridges` regenerates
the bridge registrations.
